<objective>
Publicar o repositório `amassa` no GitHub como repositório público (D-06), com a higiene de
segredos ligada **antes** do primeiro push. É a única etapa desta fase que não tem desfazer: um
segredo que entra no histórico de um repositório público é um segredo queimado mesmo que o commit
seja apagado depois, e a resposta certa é trocar a credencial, não reescrever o histórico
(`01-ARQUITETURA.md` §10).

Purpose: o repositório é público porque isso dá Actions sem limite de minutos e proteção de
branch de graça, mantendo o custo recorrente perto de zero. O preço disso é higiene absoluta, e a
higiene precisa estar no lugar antes de existir código para vazar.

Output: repositório público `amassa` com branch padrão `main`, secret scanning e push protection
habilitados, proteção contra force-push e exclusão da `main`, `README.md` e a pasta
`amassa-plataforma/` versionada (D-08).
</objective>

alguma coisa. Os portões de qualidade ficam no pipeline, que é planejado em 01-05.

pelo dono, no plano 01-06/01-07. Não criar token de acesso para o GHCR: o package será público
