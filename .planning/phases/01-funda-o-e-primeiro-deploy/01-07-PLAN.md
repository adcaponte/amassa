## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → `https://amassacerrado.com.br` | a superfície pública do sistema passa a existir a partir deste plano |
| GitHub Actions → VPS | a partir de `DEPLOY_ATIVO` verdadeiro, um push na `main` executa código no servidor |
| operador humano → servidor de produção | os dois primeiros passos deste plano são executados à mão numa máquina que agora hospeda o banco |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-31 | Spoofing | certificado TLS do domínio | high | mitigate | Caddy obtém e renova o certificado sozinho pelo ACME; conferência de cadeado sem aviso é critério de aceite explícito (INFRA-01) |
