## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] `taskkill /T /F` para derrubar a árvore de processos no Windows**
- **Found during:** Tarefa 3, primeira execução de `npm run test:site-sem-banco`
- **Issue:** O script terminava com sucesso (todas as etapas passavam), mas `processoDoApp.kill()`
  só sinalizava o processo imediato — no Windows, `spawn(..., { shell: true })` cria uma árvore
  `cmd.exe -> npm -> next`, e o servidor `next start` sobrevivia órfão, com a porta 3100 aberta.
- **Fix:** `encerrarArvoreDeProcessos()` usa `taskkill /pid <pid> /T /F` no Windows (`.kill()`
  nas outras plataformas, onde não há a árvore do shell no meio).
- **Files modified:** `scripts/testar-site-sem-banco.mjs`
- **Verification:** Reexecutado — `netstat`/`docker ps` confirmam porta e contêiner limpos
  depois do script terminar.
- **Committed in:** `e158662`

**2. [Rule 1 - Bug] Aviso de depreciação DEP0190 no `spawn` da aplicação**
- **Found during:** Tarefa 3, mesma execução
- **Issue:** `spawn("npm", [...args], { shell: true })` é o padrão que o próprio Node avisa como
  depreciado (array de argumentos com `shell: true` concatena sem escapar).
- **Fix:** Trocado para uma única string de comando (`spawn(\`npm run start -- -p ${PORTA_APP}\`, { shell: true })`),
  o padrão já usado por `rodarNpm` no resto do arquivo.
- **Files modified:** `scripts/testar-site-sem-banco.mjs`
- **Committed in:** `e158662`

**3. [Rule 1 - Bug] Dois seletores do e2e colidiam com texto de outros elementos, não com bug do app**
- **Found during:** Tarefa 3, primeira invocação de `npm run test:e2e -- --grep "site abertura"`
- **Issue:** (e) filtrava botões por `name: /^(Agenda|Encomendas)$/`, mas a barra superior também
  tem um link de navegação rotulado exatamente "Encomendas" — 3 elementos casavam, não 2. (d)
  buscava o link "O espaço" sem `exact: true`; por padrão o Playwright casa por SUBSTRING no
  nome acessível, e "Conhecer o espaço" (o botão de rolagem da abertura) contém "o espaço".
- **Fix:** (e) passou a localizar os botões por `data-testid` (`site-botao-agenda`/
  `site-botao-encomendas`), únicos por bloco; (d) ganhou `exact: true` nos dois `getByRole`.
- **Files modified:** `tests/e2e/site-abertura.spec.ts`
- **Verification:** Segunda invocação do e2e — 50 passed, 2 skipped (por viewport), 0 failed.
- **Committed in:** `e158662`
