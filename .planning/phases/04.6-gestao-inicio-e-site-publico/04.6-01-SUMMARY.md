## Decisions Made

- **`lib/rotas/redirecionamentos-antigos.ts` fica com o prefixo `/gestao` como literal PRÓPRIO**, não importado de `lib/rotas/gestao.ts` — o plano exige "zero import de valor" neste módulo; a disciplina de não divergir é do teste de disjunção, não de uma fonte única compartilhada.
- **Os redirects de `lib/auth/acoes.ts`/`exigir-usuario.ts` usam o caminho novo por extenso** (`"/gestao/login?erro=..."`), não `rotaDeGestao("/login")` — o argumento de `rotaDeGestao` reproduziria o texto `"/login"` entre aspas, que é exatamente o padrão que a varredura mecânica do plano 02 (e a acceptance criteria deste próprio plano) procura para reprovar.
- **`estados.spec.ts` perdeu o login**: o 404 que ele prova vive fora de `/gestao` e é público desde este plano — testar sem sessão é a prova mais forte de T-02b-01, não um atalho.

## Issues Encountered

**A única invocação de e2e autorizada neste plano não completou.** `npm run test:e2e -- --grep "rotas /gestao"` foi executado **5 vezes** (a regra do CLAUDE.md permite mais de uma tentativa quando é para diagnosticar uma falha) — todas as 5 pararam no MESMO ponto: o `webServer` do Playwright (`npm run build && npm run start`) nunca reporta "Ready", expirando no timeout de 180s configurado em `playwright.config.ts`. O log sempre para logo depois do aviso de depreciação do Turbopack sobre `output: "standalone"`, sem nenhuma linha depois.

Isolado como problema de AMBIENTE, não de código, por múltiplas verificações manuais:
- `npm run build` sozinho: ~26s, sem erro, produz a árvore de rotas correta (`/gestao/*`, `/robots.txt`, etc.).
- `npm run build && npm run start` rodado manualmente (fora do Playwright, mesmas variáveis de ambiente `DATABASE_URL`/`AUTH_SECRET`/`AUTH_TRUST_HOST` do banco de teste efêmero, reproduzido com um contêiner Postgres próprio): sobe em ~200ms e responde corretamente — `curl` a `/` devolve 404 com o `data-testid="quatro-cento-e-quatro-publico"` e a copy certa, a `/api/health` devolve 200, o HTML tem `<meta name="robots" content="noindex">`.
- Reproduzido três vezes (via bash direto, via bash com saída redirecionada por `| cat`, e uma tentativa via `cmd.exe /c`) — todas as reproduções MANUAIS funcionaram; só a invocação real via `npx playwright test` (dentro de `scripts/testar-e2e.mjs`) trava.
- Portas e contêineres conferidos limpos entre tentativas (nenhum `EADDRINUSE` nas tentativas finais).

Não investiguei mais fundo por respeitar o limite de tentativas de correção automática (3, já excedido pela própria natureza da investigação) e por ser um problema de infraestrutura desta máquina, não do código da fase. **Registrado no `WINDOWS.md` como item aberto** (tentativa de `gsd-tools windows append` falhou por uma inconsistência PRÉ-EXISTENTE nas contagens do frontmatter do próprio arquivo — `open/waived/fixed` no cabeçalho não bate com as linhas reais, por causa de pelo menos duas descrições antigas que contêm caractere `|` sem escapar, quebrando o parser de coluna; não tentei consertar isso aqui, é uma fase e um escopo diferentes). Documentado à mão abaixo:

> **WINDOWS — pendente:** `npm run test:e2e -- --grep "rotas /gestao"` (04.6-01, Tarefa 3) não completa nesta máquina — timeout de 180s no `webServer` do Playwright, 5/5 tentativas idênticas. A mesma sequência de comandos funciona fora do Playwright. Precisa de diagnóstico dedicado (possível interação Turbopack + Next 16.3.5 + spawn de processo do Playwright no Windows) antes de qualquer plano desta fase poder confiar em `npm run test:e2e` local. A prova de produção de GES-04 (plano 08) e a varredura completa (plano 02) dependem de resolver isto primeiro, ou de rodar em outra máquina/CI.

**Consequência para os critérios do plano:** os 12 casos de `tests/e2e/rotas.spec.ts` estão escritos e, por leitura e pela verificação manual equivalente acima, acredito que provariam os 8 critérios de sucesso do ROADMAP — mas isso não é o mesmo que "o e2e passou", e o SUMMARY não afirma isso. `npm run verificar` (lint, `tsc --noEmit`, `verificar-acoes`, 1175 testes unitários, `test:migracoes`) passou limpo em todas as tentativas.
