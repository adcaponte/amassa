## Sampling Rate

- **After every task commit:** quick run + `npm run lint` + `npx tsc --noEmit` + `npm run verificar-acoes`
- **After every plan:** `npm run verificar` + no máximo uma invocação e2e com `--grep` por tarefa
- **Before `/gsd-verify-work`:** varredura e2e completa + `npm run verificar` verdes
- **Max feedback latency:** ~60 s para o quick run
