razão de D-04 (grava no instante do toque, o Desfazer apaga) e é por isso que o teste ponta a ponta
prova que a queima sobrevive a um recarregamento, não só que o toast apareceu.

Output: as três tabelas com gatilhos, `lib/queimas/contador.ts` testado antes do código, as
primeiras três Server Actions, o índice `/queimas` de verdade (D-01) e dois arquivos de teste
ponta a ponta.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| navegador → Server Action | Toda entrada do cliente cruza aqui. Server Actions são endpoints POST alcançáveis diretamente, não só pelo botão. |
| sessão → `exigirUsuario()` | A única porta de autorização do sistema. Não há RLS atrás dela. |
| Server Action → Postgres | Escrita parametrizada pelo Drizzle; os `check`/FK do banco são a segunda linha. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Spoofing | `registrarQueima`, `criarForno`, `excluirQueima` em `lib/queimas/acoes.ts` | high | mitigate | `await exigirUsuario()` como primeira instrução do corpo de cada uma; provado por `npm run verificar-acoes`, que decide por árvore sintática do compilador do TypeScript, não por regex |
| T-04-02 | Tampering | autoria da queima (FOR-13) | high | mitigate | `esquemaQueima` tem apenas `fornoId` e `tipo`; `registradoPor` é escrito a partir de `usuarioAtual.id` e nunca lido da entrada do cliente |
| T-04-03 | Tampering | `fornoId`/`id` vindos do cliente | medium | mitigate | `esquemaId` (uuid) em toda ação que recebe identificador; FK `queimas.forno_id → fornos.id` recusa um alvo inexistente; ausência de linha vira mensagem humana, nunca stack |
| T-04-04 | Elevation of Privilege | `limite` do forno | medium | mitigate | `esquemaForno` exige inteiro `>= 10` e o banco repete em `check (limite >= 10)` — defesa em duas camadas para o dia em que um caminho de escrita novo esquecer o Zod |
| T-04-05 | Repudiation | queima sem autor | medium | mitigate | `registrado_por` sempre preenchido no caminho da interface; `on delete set null` preserva a queima quando um usuário for desativado no futuro |
| T-04-06 | Information Disclosure | mensagens de erro | low | mitigate | `ResultadoDeAcao` devolve frase em português dizendo o que fazer; o erro real vai para `console.error` no servidor e nunca ao cliente |
| T-04-07 | Tampering | migração aplicada sem supervisão | high | mitigate | `0007`/`0008` nunca são aplicadas pelo pipeline; ponto de parada de decisão na Tarefa 1 e aplicação manual com backup no plano `04-07` |
| T-04-SC | Tampering | instalação de pacote npm | high | mitigate | Este plano **não instala nenhum pacote**. `recharts` é a única dependência nova da fase e passa pelo portão de legitimidade com ponto de parada humano bloqueante no plano `04-06`, tratada como `[ASSUMED]` por não haver `## Package Legitimacy Audit` (sem RESEARCH.md nesta fase) |
</threat_model>
